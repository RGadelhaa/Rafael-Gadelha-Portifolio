04 / LABORATÓRIO DE REDES

Projetos desenvolvidos no Cisco Packet Tracer.

Topologias planejadas para representar cenários reais de conectividade, segmentação e organização de redes.

PROJETO 05 · REDE ESCOLAR

Infraestrutura de rede escolar

Projeto de uma rede para ambiente educacional, conectando setores como professores, coordenação, laboratório e alunos. A topologia também contempla uma área de servidores organizada por VLANs, permitindo separar os diferentes grupos e serviços da instituição.

VLANs Switches Access Point Servidores Endereçamento IP

Conceitos praticados: segmentação lógica, interligação de switches, conectividade sem fio, organização de setores e planejamento de endereçamento.

PROJETO 06 · REDE CORPORATIVA

Infraestrutura de rede corporativa

Simulação de uma rede empresarial com provedor, infraestrutura central, distribuição para setores administrativos, financeiro, TI, visitantes e data center. O projeto representa uma arquitetura organizada para atender usuários, serviços e diferentes níveis de acesso.

VLANs 10–100 Roteador Switch multilayer Data Center Wi-Fi

Conceitos praticados: segmentação por departamentos, rede de servidores, distribuição hierárquica, conectividade de visitantes e integração com provedor.

Ferramenta utilizada: Cisco Packet Tracer Ver meu GitHub ↗
